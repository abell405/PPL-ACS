# PPL ACS Study Guide

A searchable study guide for the FAA Private Pilot – Airplane ACS, Area of Operation I (Preflight Preparation), Tasks A–H. Every Knowledge, Risk Management, and Skills element is listed by its ACS code, with checkride questions at the end of each task.

**Live site:** https://abell405.github.io/PPL-ACS/

## Using it

- Pick a task or element code from the sidebar (the "Tasks" button on a phone).
- Search for a reg number or topic (e.g. `91.213`, `hydroplaning`) to filter and highlight matches.
- Tap a checkride question to reveal the answer.

Aircraft numbers are for the Piper Pilot 100i. Verify against the current ACS, 14 CFR, AIM, and the POH for the airplane you fly.

## Editing

The whole site is `index.html`. Edit it on GitHub and commit; the site updates in a minute or two.
